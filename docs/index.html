01 / Reviewed intent

The shared package catalog describes identity, approved versions, acquisition, and intended mirror versions. Role defaults supply floors and selection/removal policy. The validator checks consistency, not live package availability.

catalogs/chocolatey_packages.yml tools/validate_catalog.py

02 / Prepared artifacts

chocoBuild.yml runs community or wrapper tasks on a Windows build target. PowerShell bundles vendor installers and checks wrapper integrity. Iteration's install action includes chocoDeploy with a single package/local source, reusing install logic rather than duplicating it.

playbooks/chocoBuild.yml chocoBuild / iterate / install-on-target.yml

03 / Target scope

csv_to_inventory.py combines CSV and AD evidence, removes protected-OU targets, and optionally probes reachable hosts. Generated inventories carry adjacent WinRM group variables. Unknown hosts are warned, not excluded. Manual/UI inventories bypass the OU process check.

tools/csv_to_inventory.py policies/target_exclusions.yml

04 / Execute with boundaries

Fleet plays load file-based credentials from ignored vault/. Ansible reaches Windows via WinRM. chocoDeploy reconciles registry/Chocolatey state, routes sources, applies application/runtime policy, records errors and finalizes evidence. Reboots default to never. Conversion can remove a vendor install before replacement succeeds.

playbooks/chocoDeploy.yml chocoDeploy / tasks / main.yml

05 / Account for the result

Deployment writes per-run JSON and daily host HTML. Controller roll-ups combine the final result per software, resolve successful retries, and distinguish reboot advisories. report_only rebuilds existing target evidence, not a new scan. The watcher follows terminal logs; recovery tools collect missing evidence.

chocoDeploy / ops / report.yml chocoDeploy / files / fleet_summary.py

Adjacent roles / separate purposes

patchReady checks reachability/reboot/disk/Chocolatey and archives older logs. softwareUsage reads Security 4688 events and may expose private usernames/command lines. Legacy domain-join helpers are outside this deployment flow. Optional cloud samples require separately provisioned infrastructure.

playbooks/patchReady.yml playbooks/softwareUsage.yml
